# 提交环境变量清理分支

用户最终要求推送分支并返回创建合并请求的链接，由用户操作网页。

| Step | Tool | Expectation | Rollback |
|---|---|---|---|
| 核对范围和目标分支 | git status/diff | 仅包含本会话修改，目标为 github-opensource | 只读 |
| 创建独立分支并显式提交 | git switch -c、git add 指定路径、git commit | 代码和执行记录完整 | 不修改其他会话文件 |
| 推送并返回创建链接 | git push | 远端保存提交，链接包含正确目标分支 | 不强推或合并 |

- 用户接手网页后结束自动创建流程，没有代发评论或合并。
