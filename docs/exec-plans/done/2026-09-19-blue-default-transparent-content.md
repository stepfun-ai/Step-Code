# 蓝色默认主题与透明内容背景

## 方案

- 原紫色 `step` / `step-light` 更名为 `step-violet` / `step-violet-light`。
- 新蓝色深浅主题使用 `step` / `step-light`，默认仍为 `step-light/step` 自动对；已保存该设置的用户直接看到新版默认蓝色，不改写个人配置。
- 蓝色仅用于工具标题、命令、行内代码和链接等强调文本：深色强调蓝 `#82aaff`，浅色强调蓝 `#1d5dc2`；中性正文与原灰色用户 prompt 背景保留。紫金 Logo、P 色边框、wink 不变。
- 移除所有内置主题的行内代码、工具状态块、自定义消息装饰底色。用户消息背景必须保留；选中项、搜索命中、滚动条及 diff 局部高亮是功能反馈，不属于装饰蒙版，保持不变。
- 空行内代码背景不发送背景重置、不添加 chip 留白；显式设置了背景的自定义主题仍遵循自身定义。HTML 导出的空背景输出 transparent，而非误用前景色。
- 外部配色检索未返回可用资料，因此采用本地现有语法蓝作为设计参考，不声称精确复刻竞品色值。
