# 清理旧环境变量契约

## 范围

移除旧环境变量读取、写入、Shell 会话元数据注入及对应说明。
保留 Step 目录配置、终端自动探测、显式设置、请求级缓存选项和 Shell 自定义钩子。
不新增旧名称，包括测试、注释、检查脚本和执行记录；不通过编码或拼接保留名称。

| Step | Tool | Expectation | Rollback |
|---|---|---|---|
| 清理产品入口、Shell 工具和服务端环境契约 | 编辑 coding-agent、CLI 源码 | 子进程继承调用方环境，不注入会话元数据 | 逐项撤回本次改动 |
| 清理终端能力与调试开关 | 编辑 TUI 源码 | 自动探测和设置项有效，正常渲染不写日志 | 逐项撤回本次改动 |
| 固定默认缓存行为并保留显式选项 | 编辑 provider adapters | 默认短缓存，显式配置有效 | 逐项撤回本次改动 |

- npm run check 通过；已存在的包管理器配置提示未调整。
- ./test.sh 退出码 0：coding-agent 2853 passed / 66 skipped；providers 469 passed / 124 skipped；CLI 562 passed；evals 23 passed；agent-core 465 passed / 1 skipped。其余包通过；scripts 43 passed / 3 skipped。
