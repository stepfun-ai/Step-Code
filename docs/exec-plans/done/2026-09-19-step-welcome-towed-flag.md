# 小鸟骑车拖 STEPCLI 旗

## 设计

按用户新要求暂停加粗字标方案，改为右侧鹈鹕骑车、左侧燕尾旗、实线牵引。
旗面文字 `STEPCLI` 去掉单词空隙，保留七字紫金渐变、双线字形与扫光。
旗帜就近作为 UI 合成组件，复用现有九行画布、骑入进度和五秒停止机制，不新增定时器。
旗宽仍为 72 列；完整组合仍从 105 列终端开始显示。无色和窄屏维持原降级。
颜色沿用当前主题旗边和源图紫金字面，不添加调色板或主题 token。

| Step | Tool | Expectation | Rollback |
| --- | --- | --- | --- |
| 添加旗帜边缘、收紧字间布局、连接鹈鹕 | apply_patch | 字在旗内，左燕尾、右系绳，无字格覆盖 | 仅撤销本轮合成与字间调整 |
| 快照、渐变、布局和生命周期测试 | 定向 Vitest | 色阶不变、9×72 旗面、宽度和定时器无回归 | 修正本轮实现 |
| 实际 ANSI 预览并做结构检查 | 本地预览 / npm run check / git diff --check | 深浅主题可读，全部检查通过 | 仅修正本轮问题 |

不改鹈鹕源图，不调用模型、不安装依赖、不提交、不发布；已有工作区改动保留。

## 完成记录

- 新增 `step-flag.ts`，72×9 燕尾旗包住 66 列 `STEPCLI` 字面；保持原有七档紫金渐变和扫光。
- 欢迎组件复用骑入时钟移动整面旗；牵引线从旗边连续延伸到鹈鹕尾部，不覆盖源图非透明像素。未增加独立旗面飘动或定时器。
- 五个定向测试文件共 55 项通过，旗面和收紧后的字形快照已更新；覆盖旗边不覆盖字面、渐变、牵引连接、提前停止和宽度降级。
- `npm run check` 与 `git diff --check` 通过。npm 的两个既有 pnpm 配置项警告未改。
- 实际组件 ANSI 经 xterm headless 解码生成深浅主题预览，已目视检查：`/tmp/step-flag-preview.png`。预览不代表所有终端字体的最终行距效果。
- 已有欢迎测试文件仍保持原来的 9 增 9 删；未提交或修改其他用户文件。
