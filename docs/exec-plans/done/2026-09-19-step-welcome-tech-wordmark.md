# STEP CLI 科技感字标

## 范围与设计

- 基于本地 `feat/main-0919-clean`，仅调整欢迎区 STEP CLI 字标；保留鹈鹕素材、骑入与拖绳、五秒播放生命周期、信息框和窄屏降级。
- 字形采用斜切角、半格切面、镂空字腔与细投影，替换厚重实心板字。首次骑入附带一次扫光，静止后不循环、不新增定时器。
- 颜色消费当前主题的 `accent` / `text` / `dim`，不新增主题注册表或硬编码 RGB。Step 深色对应紫色主体、浅色切面、暗色投影；浅色主题自动使用深色墨色。
- 视觉结构仍为九行字标与右侧鹈鹕，下方是原有信息框；不添加装饰面板或虚构状态。
- 字标绘制就近放在 `apps/cli/src/ui/view/chrome/`，只产出单列字符格，不触及会话、工具、provider 或通用 TUI。
